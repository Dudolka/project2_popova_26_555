
# Primitive DB

Консольная база данных на Python с хранением информации в JSON-файлах.

Учебный проект по дисциплине «Python» в рамках магистратуры НИЯУ МИФИ.

## Возможности

- Создание и удаление таблиц.
- Просмотр списка таблиц и их структуры.
- Добавление, выборка, обновление и удаление записей (CRUD).
- Фильтрация записей по условию `where`.
- Поддержка типов данных `str`, `int`, `bool`.
- Автоматическое присвоение уникального идентификатора `ID`.
- Проверка корректности команд и типов данных.
- Подтверждение потенциально опасных операций.
- Кэширование результатов выборки.
- Измерение времени выполнения операций.
- Сохранение данных между запусками программы.
- Вывод табличных результатов через PrettyTable.

## Технологии

- Python 3.12
- uv — управление проектом и зависимостями.
- prompt — работа с пользовательским вводом.
- PrettyTable — отображение таблиц.
- Ruff — проверка и форматирование кода.
- unittest — автоматическое тестирование.
- asciinema — запись демонстрации работы.

## Команды базы данных

### Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя> <поле:тип> ...` | Создание таблицы |
| `list_tables` | Список таблиц |
| `info <имя>` | Информация о таблице |
| `drop_table <имя>` | Удаление таблицы |

### Операции с записями

| Команда | Описание |
|---|---|
| `insert into <таблица> values (...)` | Добавление записи |
| `select from <таблица>` | Выборка всех записей |
| `select from <таблица> where ...` | Выборка с фильтрацией |
| `update <таблица> set ... where ...` | Обновление записей |
| `delete from <таблица> where ...` | Удаление записей |

## Пример работы

### 1. Создание таблицы

```text
create_table users name:str age:int active:bool
```

Программа автоматически добавляет поле `ID:int`.

### 2. Добавление записей

```text
insert into users values ("Olga", 30, true)
insert into users values ("Anna", 25, false)
```

### 3. Просмотр записей

```text
select from users
```

Результат:

```text
+----+------+-----+--------+
| ID | name | age | active |
+----+------+-----+--------+
| 1  | Olga |  30 |  True  |
| 2  | Anna |  25 | False  |
+----+------+-----+--------+
```

### 4. Фильтрация

```text
select from users where age = 30
```

### 5. Обновление записи

```text
update users set age = 31 where name = "Olga"
```

### 6. Просмотр структуры таблицы

```text
info users
```

### 7. Удаление записи

```text
delete from users where ID = 2
```

Перед удалением программа запрашивает подтверждение:

```text
Вы уверены, что хотите выполнить "удаление записи"? [y/n]:
```

- `y` — подтвердить удаление.
- `n` — отменить операцию.

### 8. Удаление таблицы

```text
drop_table users
```

Удаление таблицы также требует подтверждения.

## Хранение данных

База данных использует JSON-файлы.

- `db_meta.json` — метаданные и структура таблиц.
- `data/<имя_таблицы>.json` — записи соответствующей таблицы.

Файлы создаются при работе приложения и сохраняют информацию между запусками.

Рабочие данные исключены из Git через `.gitignore`.

## Декораторы и кэширование

В проекте предусмотрены:

- `handle_db_errors` — централизованная обработка ошибок.
- `confirm_action` — подтверждение операций удаления.
- `log_time` — измерение времени выполнения операций.
- `create_cacher()` — создание кэша с использованием замыкания.

Кэш используется для ускорения повторных выборок и должен сбрасываться при изменении данных.
